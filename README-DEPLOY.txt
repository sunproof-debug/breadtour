원도심 빵지순례 – 인터넷에 올리기 (외부 접속)
(v3.8)

이 폴더를 그대로 무료 정적 호스팅에 올리면 친구나 휴대폰(데이터)에서도 접속할 수 있어요.

1) 올리기 – Netlify Drop (가장 쉬움)
   - https://app.netlify.com/drop 을 열고 이 폴더(bread-metaverse-site)를 화면에 끌어다 놓아요.
   - 잠시 뒤 https://이름.netlify.app 주소가 생겨요.
   - 로그인하지 않고 올린 사이트는 곧 지워져요. 무료 계정으로 가입해 사이트를 보관(Claim)하세요.
   - 주소 앞부분(사이트 이름)은 Site configuration 에서 바꿀 수 있어요.

2) 브이월드 인증키를 새 주소에 등록
   - 브이월드 > 마이페이지 > 인증키 관리에서 새 주소(https://이름.netlify.app)를 서비스 URL로 하는 키를
     발급받거나, 기존 키의 서비스 URL을 고쳐요. 2D 데이터 API와 3D 지도(WebGL)를 체크하세요.

3) 사이트에 인증키 넣기
   - 이 폴더의 vworld-config.js 를 메모장으로 열어 window.VWORLD_KEY = ''; 의 따옴표 안에 2)의 키를 넣고 저장해요.
   - Netlify 사이트 화면 > Deploys 에서 폴더를 다시 끌어다 놓아요.
   - 이제 방문자는 인증키를 몰라도 브이월드 모드를 볼 수 있어요.
   - 이 키는 누구나 볼 수 있지만 등록한 주소에서만 동작해요.

4) 주소 나누기
   - 브이월드 만화 모드: https://이름.netlify.app/vworld-v3.8.html
   - 브이월드 실사 모드: https://이름.netlify.app/vworld-real-v3.8.html
   - 기본 버전(키 없이 됨): https://이름.netlify.app/ (또는 /index-v3.8.html — 같은 페이지)

★ 인증키 없이 브이월드 건물로 보여 주기 (2·3번 대신)
   - 키가 있는 PC에서 vworld-v3.8.html 을 열고, 건물이 다 뜨면 🛰️ 브이월드 > 📦 건물 파일로 저장 을 눌러요.
   - 받은 vworld-buildings.json 을 이 폴더(index.html 옆)에 넣고 같이 올려요.
   - 그러면 기본 주소(https://이름.netlify.app/ 또는 GitHub Pages 주소)가 키 없이 브이월드 건물로 열려요.
   - 공개 전에 브이월드 이용약관에서 받은 데이터를 다른 사이트에 다시 올려도 되는지(재배포 조건) 확인하세요.

새 버전으로 바꿀 때는 새 압축파일의 HTML 파일들을 이 폴더에 넣고(index.html 은 덮어쓰기, vworld-config.js 는 그대로) 다시 끌어다 놓아요.
(예전 버전 이름의 HTML 파일이 남아 있으면 지워도 돼요.)
이번 버전은 지도 범위를 '원도심 빵지순례 구역'으로 줄여서, 브이월드 모드를 처음 열 때 건물 데이터를 한 번 더 받아요.
인터넷에 올리면 누구나 볼 수 있어요. 퀸비 사진 속 본인, 세웅이형 등 등장인물·업체의 동의를 먼저 받으세요.
